Kebijakan Privasi Aha Islamic Tracker

Terakhir Diperbarui: 17 September 2026

Selamat datang di Aha Islamic Tracker (Package Name: com.Islamic.Aha). Privasi Anda adalah amanah bagi kami. Kebijakan ini menjelaskan bagaimana aplikasi kami mengelola data Anda untuk membantu Anda tetap istiqomah dalam beribadah.

Pernyataan Privasi Utama: Kami tidak menjual data pribadi Anda kepada pihak ketiga. Semua data yang kami kumpulkan bertujuan murni untuk fungsionalitas fitur ibadah Anda.

1. Informasi yang Kami Kumpulkan

  • Informasi Akun: Saat Anda mendaftar atau masuk menggunakan Google Sign-In, kami mengumpulkan nama lengkap, alamat email, dan foto profil (opsional) untuk keperluan personalisasi dan autentikasi akun Anda.
  • Informasi Lokasi: Kami memerlukan akses lokasi perangkat Anda untuk memberikan jadwal sholat yang akurat dan menentukan arah Kiblat berdasarkan posisi Anda saat ini. Koordinat lokasi Anda dikirimkan ke layanan pihak ketiga Aladhan API (api.aladhan.com) untuk menghitung jadwal sholat sesuai metode Kementerian Agama RI.
  • Log Ibadah: Data yang Anda masukkan secara mandiri (seperti centang sholat, puasa, atau progres hafalan) disimpan untuk menampilkan statistik kemajuan spiritual Anda.
  • Informasi Perangkat & Diagnostik: Jenis perangkat, versi OS, dan data crash log dikumpulkan melalui Google Firebase Crashlytics untuk memastikan aplikasi berjalan optimal dan memperbaiki bug secara cepat. Pengumpulan data diagnostik ini hanya aktif pada versi produksi aplikasi.

2. Penggunaan Data

Data Anda digunakan secara terbatas untuk:

  • Sinkronisasi jadwal ibadah secara otomatis sesuai zona waktu Anda.
  • Memberikan notifikasi pengingat waktu sholat (Adzan) dan puasa.
  • Menampilkan grafik progres ibadah mingguan atau bulanan.
  • Menganalisis dan memperbaiki masalah teknis (crash & bug) pada aplikasi.

3. Penyimpanan Data

Sebagian besar data ibadah Anda disimpan secara lokal di perangkat Anda dengan enkripsi AES-256. Jika Anda menggunakan fitur sinkronisasi akun (opsional), data Anda akan dienkripsi dan disimpan dengan aman di server Google Firebase menggunakan standar keamanan industri.

4. Berbagi Data dengan Pihak Ketiga

Kami hanya membagikan data Anda secara terbatas kepada pihak ketiga berikut untuk keperluan fungsionalitas aplikasi:

  • Aladhan API (api.aladhan.com): Menerima koordinat lokasi Anda untuk menghitung jadwal sholat.
  • Google Firebase: Menyimpan data akun dan log ibadah (Firestore), serta mengumpulkan data diagnostik crash (Crashlytics).
  • Google Play Integrity: Memverifikasi integritas aplikasi untuk keamanan API.

Kami tidak membagikan data Anda kepada pihak ketiga untuk keperluan iklan, pemasaran, atau penjualan data.

5. Izin Perangkat (Permissions)

Aplikasi akan meminta izin untuk:

  • Lokasi: Wajib untuk fitur Waktu Sholat & Kiblat.
  • Notifikasi: Untuk mengirimkan alarm pengingat ibadah.
  • Exact Alarm: Untuk memastikan pengingat sholat berbunyi tepat pada waktunya.

6. Hak Anda sebagai Pengguna

Anda memiliki hak penuh untuk:

  • Menghapus semua data log ibadah melalui menu pengaturan.
  • Mematikan akses lokasi kapan saja melalui pengaturan sistem (meskipun fitur waktu sholat tidak akan akurat jika dilakukan).
  • Menghapus akun Anda secara permanen dari server kami, termasuk seluruh data yang tersimpan, melalui menu Pengaturan > Keamanan Akun > Hapus Akun Permanen di dalam aplikasi.
