Kebijakan Privasi Aha Islamic Tracker

Terakhir Diperbarui: 14 Februari 2026

Selamat datang di Aha Islamic Tracker. Privasi Anda adalah amanah bagi kami. Kebijakan ini menjelaskan bagaimana aplikasi kami mengelola data Anda untuk membantu Anda tetap istiqomah dalam beribadah.

Pernyataan Privasi Utama: Kami tidak menjual data pribadi Anda kepada pihak ketiga. Semua data yang kami kumpulkan bertujuan murni untuk fungsionalitas fitur ibadah Anda.

1. Informasi yang Kami Kumpulkan

  • Informasi Lokasi: Kami memerlukan akses lokasi perangkat Anda untuk memberikan jadwal sholat yang akurat dan menentukan arah Kiblat berdasarkan posisi Anda saat ini.
  • Log Ibadah: Data yang Anda masukkan secara mandiri (seperti centang sholat, puasa, atau progres hafalan) disimpan untuk menampilkan statistik kemajuan spiritual Anda.
  • Informasi Perangkat: Jenis perangkat dan versi OS untuk memastikan aplikasi berjalan optimal dan bebas bug.

2. Penggunaan Data

Data Anda digunakan secara terbatas untuk:

  • Sinkronisasi jadwal ibadah secara otomatis sesuai zona waktu Anda.
  • Memberikan notifikasi pengingat waktu sholat (Adzan) dan puasa.
  • Menampilkan grafik progres ibadah mingguan atau bulanan.

3. Penyimpanan Data

Sebagian besar data ibadah Anda disimpan secara lokal di perangkat Anda. Jika Anda menggunakan fitur sinkronisasi akun (opsional), data Anda akan dienkripsi dan disimpan dengan aman di server kami menggunakan standar keamanan industri.

4. Izin Perangkat (Permissions)

Aplikasi akan meminta izin untuk:

  • Lokasi: Wajib untuk fitur Waktu Sholat & Kiblat.
  • Notifikasi: Untuk mengirimkan alarm pengingat ibadah.
  • Penyimpanan: Untuk menyimpan pengaturan profil atau data offline (seperti konten doa).

5. Hak Anda sebagai Pengguna

Anda memiliki hak penuh untuk:

  • Menghapus semua data log ibadah melalui menu pengaturan.
  • Mematikan akses lokasi kapan saja melalui pengaturan sistem (meskipun fitur waktu sholat tidak akan akurat jika dilakukan).
  • Menghapus akun Anda secara permanen dari server kami.
