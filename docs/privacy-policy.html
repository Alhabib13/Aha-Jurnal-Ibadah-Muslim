Kebijakan Privasi Aha Islamic Tracker

Terakhir Diperbarui: 14 Oktober 2026 (versi aplikasi 1.2.0)

Selamat datang di Aha Islamic Tracker (Package Name: com.Islamic.Aha). Privasi Anda adalah amanah bagi kami. Kebijakan ini menjelaskan data apa saja yang dikelola aplikasi, untuk apa, dan bagaimana Anda dapat menghapusnya.

Pernyataan Privasi Utama: Kami tidak menjual data Anda dan tidak menggunakannya untuk iklan. Data dipakai untuk menjalankan fitur ibadah dan, mulai versi 1.2.0, untuk penelitian pengembangan aplikasi seperti dijelaskan pada bagian 3.

1. Informasi yang Kami Kumpulkan

  • Informasi Akun: Jika Anda mendaftar atau masuk (email atau Google Sign-In), kami menyimpan nama, alamat email, dan foto profil (opsional) untuk autentikasi dan personalisasi. Aplikasi tetap dapat dipakai tanpa akun (mode tamu).
  • Informasi Lokasi: Lokasi perangkat dipakai untuk menghitung jadwal sholat. Koordinat dikirimkan ke layanan pihak ketiga Aladhan API (api.aladhan.com). Lokasi tidak disimpan di server kami dan tidak dipakai untuk penelitian.
  • Catatan Ibadah: Data yang Anda masukkan sendiri, yaitu sholat wajib dan sunnah, puasa, dzikir yang Anda pilih sendiri (termasuk nama dzikir yang Anda tulis dan target hitungan bila Anda mengaturnya), sesi tilawah (bacaan harian, hafalan, murajaah) beserta jumlah ayat, jumlah halaman, dan juz yang dihitung aplikasi dari rentang ayat yang Anda pilih, serta jilid dan halaman Iqro (atau metode sejenis). Setiap catatan menyimpan tanggal ibadah, jam pencatatan, dan zona waktu perangkat saat itu (misalnya +07:00).
  • Daftar Dzikir: dzikir yang Anda tambahkan, cara mencatatnya, dan target hitungan bila Anda mengaturnya.
  • Penanda & Target Tilawah: posisi surah dan ayat terakhir untuk tiap jenis sesi tilawah, posisi Iqro terakhir, dan target halaman harian bila Anda mengaturnya.
  • Profil Ibadah: Jenis kelamin (untuk fitur Mode Cuti dan pengingat Sholat Jumat; tidak bisa diubah setelah disimpan), rentang usia (di bawah 13, 13–17, atau 18 tahun ke atas) beserta pernyataan izin orang tua/wali bagi pengguna di bawah 18 tahun, status Mode Cuti, serta tanggal-tanggal ketika Mode Cuti aktif. Jika Anda masuk ke akun, data ini disinkronkan ke server agar tidak hilang saat berganti perangkat.
  • Suara Pengingat: pilihan suara untuk tiap waktu sholat disimpan di perangkat. Bila Anda memilih file suara sendiri, aplikasi hanya membaca file itu di perangkat untuk membunyikan pengingat; file tersebut tidak diunggah ke mana pun.
  • Informasi Perangkat & Diagnostik: Jenis perangkat, versi OS, dan crash log melalui Google Firebase Crashlytics untuk memperbaiki bug.

2. Penggunaan Data

  • Menampilkan jadwal sholat sesuai lokasi dan zona waktu Anda.
  • Mengirim notifikasi pengingat ibadah.
  • Menampilkan statistik, heatmap, dan streak ibadah Anda.
  • Menyinkronkan data antar-perangkat bila Anda masuk ke akun.
  • Menganalisis dan memperbaiki masalah teknis aplikasi.
  • Penelitian pengembangan aplikasi (lihat bagian 3).

3. Penggunaan Data untuk Penelitian

Mulai versi 1.2.0, catatan ibadah dipakai dalam penelitian tugas akhir pengembang aplikasi. Tujuannya mengembangkan fitur Aha, antara lain pengingat yang lebih tepat waktu. Di dalam aplikasi Anda diminta memilih Setuju atau Tidak. Bila Anda tidak setuju, aplikasi tetap dapat dipakai sepenuhnya dan catatan Anda hanya disimpan di perangkat, tidak dikirim untuk penelitian. Bila Anda setuju (termasuk setuju belakangan), catatan yang sudah ada di perangkat ikut dikirim.

  • Data yang dipakai: jenis ibadah, tanggal ibadah, jam pencatatan, zona waktu perangkat, status (dikerjakan / tidak / udzur), cara mencatat (lewat tombol di notifikasi pengingat atau dari dalam aplikasi), jumlah ayat, halaman, juz, atau jilid, selisih menit antara pencatatan sholat/dzikir dan waktu adzan, serta profil ibadah dan rentang usia.
  • Selisih dari waktu adzan dihitung di perangkat Anda dari jadwal sholat di aplikasi. Yang dikirim hanya angka selisihnya (misalnya 12 menit); lokasi dan jadwal sholat Anda tidak dikirim ke server.
  • Yang tidak dipakai: nama, alamat email, foto, lokasi, dan kontak. Data penelitian dihubungkan dengan ID pengguna acak, bukan dengan identitas Anda.
  • Penyajian hasil: hasil penelitian dilaporkan dalam bentuk agregat (gabungan banyak pengguna), tidak per individu.
  • Pengguna tamu: catatan disimpan di perangkat dan baru dikirim ke server setelah Anda masuk ke akun.
  • Berhenti & penghapusan: Anda dapat berhenti ikut penelitian kapan saja dan menghapus data penelitian yang sudah terkirim tanpa menghapus akun, melalui Pengaturan › Privasi & Data. Menghapus akun juga menghapus seluruh data penelitian milik Anda dari server.

4. Penyimpanan & Keamanan Data

Catatan ibadah disimpan di penyimpanan internal aplikasi pada perangkat Anda. Pengaturan aplikasi dan file cadangan (ekspor) dienkripsi dengan AES-256. Jika Anda masuk ke akun, data disimpan di Google Firebase (Cloud Firestore). Data dikirim melalui koneksi terenkripsi (HTTPS) dan dienkripsi oleh Google saat tersimpan di server. Akses ke data di server dibatasi aturan keamanan sehingga setiap pengguna hanya dapat membaca dan mengubah datanya sendiri.

5. Berbagi Data dengan Pihak Ketiga

  • Aladhan API (api.aladhan.com): menerima koordinat lokasi untuk menghitung jadwal sholat.
  • Google Firebase: autentikasi akun (Authentication), penyimpanan data akun, catatan ibadah, dan data penelitian (Cloud Firestore), serta diagnostik crash (Crashlytics).
  • Google Play Integrity: memverifikasi integritas aplikasi untuk keamanan API.

Kami tidak membagikan data Anda untuk iklan, pemasaran, atau penjualan data.

6. Izin Perangkat (Permissions)

  • Lokasi: untuk jadwal sholat sesuai posisi Anda.
  • Notifikasi: untuk pengingat ibadah.
  • Exact Alarm: agar pengingat berbunyi tepat waktu.

7. Hak Anda sebagai Pengguna

  • Menghapus data ibadah di perangkat melalui menu Pengaturan > Hapus semua data lokal.
  • Mematikan akses lokasi kapan saja melalui pengaturan sistem (jadwal sholat akan memakai waktu bawaan).
  • Menghapus akun secara permanen, termasuk seluruh data di server (catatan ibadah, profil ibadah, daftar dzikir, penanda dan target tilawah, serta data penelitian), melalui menu Pengaturan > Akun & Keamanan > Hapus akun permanen.

8. Atribusi Data

Data batas halaman dan juz mushaf Madinah yang dipakai untuk menghitung sesi tilawah berasal dari Tanzil Quran Metadata (tanzil.net), dilisensikan dengan Creative Commons Attribution 3.0. Aplikasi hanya memakai angka posisi (jumlah ayat, awal halaman, awal juz), tanpa teks Al-Qur'an, terjemahan, atau audio.
